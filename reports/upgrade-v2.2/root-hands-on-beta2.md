# beta.2 发布前实际试玩

2026-09-27，主开发代理在本地静态生产候选中，通过浏览器实际界面完成一局。没有使用 API 指令、注入局面或跳过回合。难度为普通进攻型，使用 985 + 985 预设、完整开局和慢练习。

流程覆盖：首页应用预设 → 应对选牌 → 起手 → 九轮真实对局 → 胜利结算 → 本局回放 → 游客长期保存登录入口 → 取消登录保留结算 → 返回首页。终局己方 19、对方 -2 心态；回放共 62 步、157 个公开事件，确定性重放校验一致，最终场面与结果吻合。另实际操作了播放、暂停和末尾跳转。

实玩发现并修复：慢练习准备阶段错误倒计时；机器人连续动作过快；普通角色攻击重复播放纸飞机再冲撞；完整开局没有保留预设三张应对牌；从桌面切到窄屏时 Offer 抽屉遮挡场上操作；动画忙碌时点击己方角色误开规则弹窗。手机教程面板遮挡目标的问题另有真实 390px/1440px 回归。

修复后另开完整开局，实际等待超过原来的期限后仍保持应对选牌页；预选三张符合当前预设，并可正常进入换起手。换起手也保持不限时，正常开局后复查了单击上场、选己方实习搭子再点敌方挡话角色的直接攻击，没有重复纸飞机段。289 项单测通过；移动教程与预设准备新增 5 项浏览器检查通过。六套最终构筑的 360 局固定种子检查详见 [预设报告](../STARTER_DECKS.md)。这些是开发验证，不计作 48 个独立验收样本。

按用户最新要求，本轮优先修复并上线；大规模独立验收及 A08 最终候选重拍暂未执行，不标记通过。公网部署与发布后检查以部署记录为准。

最终生产候选另执行 22 项关键浏览器检查（布局、音频、攻击、纸飞机、应对选牌和教程遮挡）及 11 项 Cloudflare 集成测试，均通过。分批测试不合并成独立验收人数。

静态页面现有完整套件 15/15 通过，覆盖两种视口的真实游客教程操作、刷新恢复、账号保存界面、造卡和浏览器人机 Worker。此套件的云端账号响应为隔离夹具，不能代替公网联机。
