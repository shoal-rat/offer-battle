# 秋招斗兽棋：Offer 开打
## 完整游戏设计书 · v2.0｜双学历与校友主角版

**一句话定位：把同学群里比 Offer 的嘴仗，变成一场可以出牌、拆台、反杀的二次元卡牌对战。**

**主标语：工资先亮，底牌后出。**

本书是产品、玩法、美术、内容生成与程序开发的统一规格。首发采用手机竖屏网页。玩家输入自己的 Offer，把它生成为可爱的二次元职场小人，再带着这些角色与朋友开打。规则版本为 `2.0.0`，数值采用本书与配套 `rules_catalog.json` 的原型基准。

---

# 1. 游戏要提供什么体验

## 1.1 核心场景

群聊里有人亮出高薪 Offer。另一个人立刻问工时。第三个人开始聊稳定。有人把学校搬出来，有人开始算三十五岁。这个来回拆台的过程，就是对局本身。

高工资直接带来大排面。公司性质决定角色气质。岗位决定主技能。双休、期权、弹性安排等条款变成具体效果。学校背景提供英雄技能。玩家既能炫自己的牌，也能抓住别人牌上的破绽。

理想对话是：“我这个包够大吧？”“够大，所以这张三十五岁一直给你留着。”随后对方交出《转管理》，旁边再翻开《合同写着呢》。接下来的胜负由留牌、时机与资源分配决定。

## 1.2 玩家循环

录入 Offer → 看见自己的二次元角色 → 给角色挑一句欠揍台词 → 组好三张 Offer → 把房间发进群 → 看对方亮牌 → 选三张拆台工具 → 开打 → 生成战报 → 换牌再来。

生成完成页必须同时出现“晒一下”和“拿去开打”。收藏页能看到角色表情、入场台词、打出的名场面。对局胜利与角色收集形成两条回访路径。

## 1.3 基本产品规格

| 项目 | 定稿 |
|---|---|
| 主要平台 | 手机竖屏网页，桌面浏览器自适应 |
| 核心模式 | 一对一轮流行动，好友房优先 |
| 对局时长目标 | 4—7 分钟 |
| 每人携带 | 1 个主角、3 张 Offer、15 张通用牌 |
| 首发内容 | 10 个第一学历、11 个第二学历选择、110 种有序组合、11 个 Offer 模板、7 种附加条款、30 张通用牌 |
| 视觉 | 可爱的二次元职场小人，约 2.5—3 头身 |
| 情绪 | 炫耀、戏谑、拆台、逆袭、嘴硬 |
| 分享对象 | 同学群、求职群、朋友私聊 |
| 首发商业入口 | 专属立绘、表情、卡套、入场演出、战报主题 |

所有玩家界面采用生活化表达。下面的对应关系同时用于规则文字、教程与战斗日志。

| 玩家看到的词 | 具体含义 | 界面示例 |
|---|---|---|
| 心态 | 主角的生命值 | 心态 24 / 30 |
| 时间 | 每回合用于行动的资源，单位为小时 | 本回合还剩 3 小时 |
| 上桌 | 把一个角色放到场上 | 花 5 小时上桌 |
| 排面 | 角色每次交锋造成的基础伤害 | 排面 7 |
| 底气 | 角色还能承受的伤害 | 底气 4 / 6 |
| 开怼 | 角色主动攻击角色或主角 | 选择开怼对象 |
| 挡话 | 对方角色开怼时必须优先选择它 | 先过我这关 |
| 拆台牌 | 直接使用后结算的行动牌；包括伤害、恢复、调度、话题等效果 | 打听工时 |
| 助阵角色 | 通用牌召唤的同学、学长、猎头等 | 内推学长 |
| 留一手 | 盖住一张反话牌，满足条件后自动触发 | 他还留了一手 |

主角自己无法开怼，可以使用学历技能。第一学历和第二学历每回合共用一次发动机会。Offer 角色和助阵角色共享四个场上位置。所有界面的术语必须与此表一致。

# 3. 一局游戏的完整结构

## 3.1 带牌与赛前选牌

玩家在收藏页选择第一学历与第二学历，再选择三张不同的 Offer。同一份 Offer 的不同立绘共用一个身份，一局只能带一个版本。三张 Offer 放在独立的公开区域。它们无需抽取，可以在支付足够时间后直接上桌。

通用牌由十二张基础牌与三张赛前应对牌组成。基础牌从 N01—N24 中选择，同名最多两张。应对牌从 F01—F06 中选择三张不同的牌。总牌库严格为十五张，三张 Offer 另算。

匹配成功后，双方先看到对手的双学历组合与三张 Offer，再用二十秒选择三张应对牌。双方的选择保持隐藏。超时采用事先保存的应对方案。完成选择后才洗牌、发起手牌。

新手可直接使用预设牌组。所有通用牌从开始即可使用。没有三份个人 Offer 时，可以从公共体验卡中补齐。个人卡与公共体验卡在收藏页保留各自的来源标识。

## 3.2 起手与换牌

先手获得三张手牌，后手获得四张。双方各可更换至多两张：先从剩余牌库抽取替换牌，再把被换掉的牌洗回牌库。

双方第一个自己的回合也会抽一张牌。先后手在开局随机确定。后手没有额外的临时时间道具。

## 3.3 回合与轮次

“一个回合”指一名玩家的一次行动机会。“一轮”包含先手的一回合与后手的一回合。第一轮每人有一小时；第二轮每人有两小时；之后逐轮增加，最多八小时。每个自己的回合开始时，时间补满，未使用的时间无法跨回合保留。

每回合有三十秒操作时间。选择英雄技能、出牌、开怼与结束回合共享这个时间。强制选项超时采用稳定默认值，例如按当前牌库顺序选第一张。新手教学关闭回合倒计时。

## 3.4 场上与手牌

每人有四个场上位置，手牌上限为八张。Offer 区不占手牌上限。

抽到第九张牌时，该牌公开弃置。场上收回的角色遇到满手时，也公开弃置；Offer 以这种方式离开不会额外扣心态。临时召唤物收回后直接消失，不进入手牌。

场上没有空位时，无法上桌。需要召唤两个角色的牌要求两个空位。非法操作不会消耗时间、手牌或谈薪机会。

## 3.5 开怼规则

普通角色上桌当回合无法主动开怼。从下一次自己的回合开始，每个角色每回合可以主动开怼一次。反击次数没有限制。排面为零的角色无法主动开怼。

角色开怼角色时，双方同时按当前排面扣除对方底气。角色开怼主角时，主角扣除相应心态，主角不反击。受到的底气伤害持续保留。

对方有挡话角色时，主动开怼必须优先指向其中一个挡话角色。拆台牌与英雄技能的合法目标由各自卡面决定，挡话不会改变这些目标。

## 3.6 Offer 退场反馈

一张 Offer 因底气归零或被直接退场而离开时，其拥有者额外失去两点心态。助阵角色退场不扣主角心态。

收回、谈薪、收回时满手弃置都不触发这两点心态损失。谈薪只消耗本局使用权。收藏中的卡始终保留。

## 3.7 胜负与收尾

主角心态初始为三十，恢复上限也是三十。伤害结算节点出现一方心态不大于零时，对局结束。同一个同时伤害节点使双方都不大于零时，判定平局。

牌库为空时，每次要求抽一张牌都会改为增加一次焦虑，并失去等于当前焦虑次数的心态，依次为一、二、三……。一张“抽两张”的牌会依次尝试抽两张。

第十二轮的后手回合完整结算后，心态较高者获胜。心态相同时平局。常规退场反馈、反话与回合结束效果先结算，再执行轮次上限判定。

# 4. 核心机制一：真实 Offer 的数值化

## 4.1 输入表单

基础字段包括公司显示名、公司性质、行业、岗位、城市、薪酬构成。公司性质与行业分别填写，例如“民营／互联网”“外资／制造”“国企／金融”。创业阶段作为单独字段。

薪酬表单分别记录税前月固定工资、保证发薪月数、年度固定补贴、额外目标现金奖金、当年股票或期权折算、一次性签字费。工作条款包括双休、弹性安排、通勤短、安家补助、轮岗、保障条款等。

玩家上传图片、粘贴文字或手填均可。提取结果先进入确认页。缺失字段保持待填，年薪与月薪必须标清单位。已经包含在保证月数里的奖金不能再算一次。

## 4.2 年包口径与档位

游戏计价年包采用：

`固定年现金 = 月固定工资 × 保证发薪月数 + 年度固定补贴`

`计价年包 = 固定年现金 + 额外目标现金奖金 + 当年股票或期权折算`

一次性签字费单列展示。多年授予总额需要先转换为当年的计划额度，再参与计价。卡面可展开查看固定现金、浮动现金、权益构成。

| 计价年包 | 原始上桌时间 c | 基础排面 | 基础底气 |
|---|---:|---:|---:|
| 低于 15 万元 | 2 小时 | 2 | 3 |
| 15 万元至不足 25 万元 | 3 小时 | 3 | 4 |
| 25 万元至不足 40 万元 | 4 小时 | 4 | 5 |
| 40 万元至不足 60 万元 | 5 小时 | 5 | 6 |
| 60 万元至不足 90 万元 | 6 小时 | 6 | 7 |
| 90 万元及以上 | 7 小时 | 7 | 8 |

高工资拥有直接可见的大数值，也需要更长的上桌时间。超过最高档后，卡面仍展示具体年包，战斗档位保持七小时。公司规模、学校名次、立绘精致度不会额外进入这张表。

## 4.3 玩法模板

模板根据已经确认的行业、岗位与公司性质确定。模板会替换基础身材形状，并提供一个主效果。以下表中的 c 为上桌时间，初始排面与底气都至少为一。

| 编号／模板 | 初始排面 | 初始底气 | 主效果 |
| --- | --- | --- | --- |
| T00 普通同事 | c | c + 1 | 上桌：恢复自己1点心态。 |
| T01 一线卷王 | c + 2 | c − 1 | 主动开怼时，自己失去1点心态，与本次交锋伤害一起结算。 |
| T02 稳定守岗 | c − 1 | c + 2 | 挡话。 |
| T03 流程大师 | c − 1 | c | 上桌：可以收回一张自己的其他Offer。 |
| T04 硬件老法师 | c − 1 | c + 1 | 年龄至少31岁时排面+2；35岁时底气上限额外+2。阶段带来的底气上限变化保持已受伤害不变。 |
| T05 项目经理 | c − 1 | c | 上桌：可以使一个其他友方角色排面+1，底气上限与当前底气各+1。 |
| T06 销售冠军 | c + 1 | c − 1 | 主动开怼对方主角并造成心态伤害后，抽1张牌。 |
| T07 测试拆台王 | c − 1 | c | 上桌：可以使一个敌方角色失去2点底气。 |
| T08 人事终面官 | c − 1 | c | 上桌：可以使一个敌方角色在其拥有者下个回合无法主动开怼。 |
| T09 咨询方案师 | c − 1 | c | 上桌：查看自己牌库顶最多3张，选1张加入手牌，其余洗回牌库。这是拿牌；空牌库时视为抽1张并结算焦虑。 |
| T10 创业合伙人 | c | c | 每提升一个职场阶段，排面比新人阶段多1，最多+3。 |

模板匹配优先级为：人事岗位、测试岗位、销售岗位、管理岗位、咨询行业、制造研发、国企或央企职能、外资产品或项目、带权益的创业岗位、互联网或游戏的一线开发算法岗位、普通同事。

各项对应 T08、T07、T06、T05、T09、T04、T02、T03、T10、T01、T00。条件重叠时采用靠前的匹配。玩家在生成确认页可以修正公司类型与岗位归类。结果页展示本次匹配的依据。

## 4.4 附加条款

每张 Offer 最多启用一个附加条款。具备多项条件时，玩家从符合输入的条款中选择一个。其余条款继续展示在详情页。

启用条款需要支付一个初始底气点。如果底气已经为一，则支付一个初始排面点。支付后排面与底气都至少为一。这个价格在生成卡片时固定下来。

| 编号／条款 | 效果 |
| --- | --- |
| B01 双休 | 自己的回合结束时，恢复自己1点心态。 |
| B02 弹性安排 | 上桌当回合可以主动开怼角色；当回合无法主动开怼主角。 |
| B03 通勤短 | 上桌：恢复自己2点心态。 |
| B04 期权 | 年龄至少31岁时排面+2；35岁时改为总共+3。 |
| B05 安家补助 | 上桌：抽1张牌。 |
| B06 轮岗 | 上桌二选一：排面+1；或底气上限与当前底气各+2。 |
| B07 保障条款 | 每次上桌后，首次受到对手拆台牌的底气伤害减少2，最低0。消耗后不再生效。 |

双休、弹性安排、通勤短共同带有“生活”标签，用于聊天话题判定。期权指 B04 条款，创业合伙人的主技能单独归类，二者在结算中分别记录。

## 4.5 生成结果与重抽

同一份已确认输入、同一套规则版本、同一条款选择，必须得到相同战斗属性。重新生成只改变立绘、卡名和吐槽。

用户修改薪酬、岗位或条款后，生成一个新的规则修订。已经开始的对局使用开局快照。收藏页用修订记录保留变化原因。

# 5. 核心机制二：把另一份 Offer 拿去谈薪

每人每局有一次谈薪机会。选择一张从未上桌、仍在 Offer 区的卡作为筹码，再选择另一张仍在 Offer 区的卡立即上桌。

| 作为筹码的 Offer 原始耗时 | 本次优惠 |
|---|---:|
| 2—3 小时 | 少花 1 小时 |
| 4—5 小时 | 少花 2 小时 |
| 6—7 小时 | 少花 3 小时 |

筹码卡本局永久退出可用区。被优惠的 Offer 最少花一小时。谈薪、扣时间、上桌是一个原子操作；时间不足、目标非法或没有位置时，整个操作不执行。

例如，把一张六小时的 Offer 拿去谈薪，可以让另一张七小时 Offer 在第四轮上桌。代价是失去前一张牌的整局战斗价值。拿一张两小时保底牌去谈，只能省一小时。

界面同时展示“现在少花多少时间”“本局失去哪张牌”。操作按钮显示：“拿这张去抬价”。完成后，筹码卡盖上“用于谈薪”的印章。

内推便条可与谈薪叠加。返场便条只作用于绑定Offer从手牌上桌。实际耗时统一按 `max(1, 原始耗时 + 最大有效学校加时 + 其他加时 − 谈薪优惠 − 内推优惠 − 返场优惠)` 计算。符合条件的便条在上桌时一起消耗。所有“原始耗时”条件始终读取卡片生成时的耗时。

# 6. 核心机制三：从应届到三十五岁

## 6.1 年龄轨道

所有 Offer 第一次上桌时从二十二岁开始。每到一个新的己方回合开始，仍在场上的 Offer 向下一阶段推进一次：

| 阶段 | 游戏年龄 | 场上提示 |
|---|---:|---|
| 新人 | 22 岁 | 刚入职 |
| 熟手 | 27 岁 | 开始扛活 |
| 骨干 | 31 岁 | 下次到三十五 |
| 资深 | 35 岁 | 资深阶段 |

到三十五岁后停留在该阶段。Offer 在手牌和 Offer 区时不推进年龄。助阵角色没有年龄。

收回保留年龄。伤害、临时增减、优化通知与本次上桌的状态会清除。再次上桌时，按保留的年龄重新计算本身具备的阶段能力。

## 6.2 一线与长期成长

T01 一线卷王在前期拥有更高的排面，主动开怼会消耗自己的心态。三十五岁时，它会成为《三十五岁》的合法目标。

T04 硬件老法师在三十一岁提高排面，三十五岁提高底气。T10 创业合伙人每推进一个阶段提高排面。期权条款在三十一岁和三十五岁兑现攻击加成。

这样，同一条时间线同时制造风险与收益。前期出大牌的人需要规划退路，长期牌需要争取存活时间。

## 6.3 《三十五岁》的完整交互

《三十五岁》耗时两小时，只能选择已经三十五岁、仍带有一线标签的敌方 Offer。使用后，目标身上出现“优化通知”。在使用者下一个回合开始时检查目标：它仍处于同一次上桌、仍有一线标签、仍满足年龄条件，就让它退场。

持有者会获得一个完整的行动回合。可以使用《转管理》移除一线标签；可以用《跳槽》收回；也可以让它完成最后一轮输出。已经预先盖下的《合同写着呢》能够在《三十五岁》被打出时取消它。

通知锁定本次上桌实例。目标收回时通知取消。重新上桌产生新的实例，旧通知无法追杀新实例。收回仍保留三十五岁的年龄，后续新的《三十五岁》仍可选中它。

# 7. 核心机制四：把话题带跑

双方共享一个聊天话题。每轮开始采用对应轮次的默认话题。

| 轮次 | 默认话题 | 规则 |
|---|---|---|

# 8. 双学历系统：第一学历定打法，第二学历留一招

## 8.1 选择结构

主角由“第一学历＋第二学历”组成。第一学历提供每回合可用的主技能；第二学历提供一项第四轮解锁、每局限用一次的进修技能。两项技能共同使用每个己方回合一次的学历行动机会。

第一学历有十个入口。第二学历沿用这十个入口，另加“直接就业”。一共110种有先后顺序的合法搭配。同一学校可以同时出现在两个槽位。每个槽位只保存一个流派ID，选择校友流派就使用校友流派定义，不再叠加985主技能。学校展示信息、榜单信息与本局技能选择分开保存。

第一学历决定主角的基础造型、开局称号和主技能。第二学历叠加胸针、毕业章和进修技能。两项选择在开局同时公开，对手选应对牌时就能看见。四轮之前，第二学历按钮显示“第4轮毕业”，不接受发动命令。

一个己方回合使用过任意一个学历技能，另一项立即置灰。进修技能成功发动后，本局进入“已毕业兑现”状态。非法目标、时间不足、位置已满不会消耗机会。合法的信息查看技能在显示隐藏牌之前就扣时间并占用机会。

## 8.2 海外三档

海外 Top 50 对应第1至50名，海外 Top 100 对应第51至100名，海外 100+ 对应第101名及以后。三个入口互斥。数字50进入Top 50，数字100进入Top 100，数字101进入100+。

玩家可填写所选榜单、榜单年份、学校显示名和名次。档位也可手动选择。没有具体名次时保留空字段，生成模型读取玩家已经确认的档位。单局快照固定该选择，运行中不会刷新榜单。

海外造型围绕旅行箱、毕业袍、项目资料、护照夹、跨时区办公道具展开。三档各有自己的姿态和技能，不额外增加年包数值。

## 8.5 校友流派特供：校友主角·全校撑腰

主角称号为“校友主角”，展示角标为“校友指定最强”。普通主角卡框、操作按钮和伤害字体保持统一，校友流派额外拥有一套夸张入场和校友集合演出。

**第一个阶段：校友集合。** 花2小时，恢复1点心态，获得1枚公开签到章。下一个自己的回合可以再花2小时集合一次。签到章上限为2，满心态时也能集合。两次集合占用两个不同己方回合的学历行动。

**第二个阶段：全校撑腰。** 满2枚签到章后，主技能切换为全校撑腰。花2小时，选择一张场上己方Offer，使其排面＋4、底气上限＋4，已受伤害保持不变。结算消耗全部签到章，并写入本局大招已使用。没有己方Offer时，这一步无法发动。

**第三个阶段：校友饭局。** 大招使用后，主技能固定变为花2小时恢复2点心态。整局不会重新集合签到章。

全校撑腰是首发数值最大的单目标学历强化。完整兑现需要累计6小时、三个不同己方回合的学历行动，以及一张留在场上的Offer。它会保留年龄，保留已经用掉的开怼次数。它不附加免疫，不重新触发登场，不解除优化通知，不提供额外场位。

强化跟随当前上桌实例。角色收回、退场或以满手规则弃置后，强化清除。校友流派已经花掉的大招次数留在主角的本局状态中。重新上桌或换立绘都无法恢复。

## 8.6 校友流派＋校友流派：本硕连读·校友主角

第一学历校友流派带全校撑腰。第二学历校友流派带母校再认证，花3小时，为己方一张Offer提供＋2排面、＋2底气上限。

两个技能在不同回合落到同一个上桌实例上时，可以累计＋6排面、＋6底气上限。包含两次集合，总共需要9小时和四次不同己方回合的学历行动。其他来源的强化独立计算。

本硕连读提供专属称号、双份毕业章和升级演出。系统不产生第三个技能。第一学历没有校友流派的组合不会获得签到章；第二学历校友流派始终只提供母校再认证。

释放大招时，六个装饰性校友从牌桌边缘探头，合力把一块“全校撑腰”牌匾架到目标身后。这些校友只存在于动画层。场上角色仍然最多四个。双校友流派在牌匾旁再盖一枚“本硕连读”章。

建议台词：“排名先放旁边，我把母校搬上来了。”双校友流派追加：“第一学历校友流派，第二学历还是校友流派。教育背景形成闭环。”对方成功收回强化目标时可播放：“母校刚到，Offer先下班了。”

## 8.7 对抗校友流派的具体窗口

两枚签到章都对双方可见。第二枚盖好后，提示“下个己方回合可用全校撑腰”。准备阶段累计花掉4小时，玩家可以趁这段时间铺场、压低心态，或清掉对方的Offer。

大招只强化已有的Offer。对手提前拆空Offer区外的场面，可以让校友流派暂时无目标。大招落地后，流程重走能收回目标并移除这次强化；三十五岁仍检查年龄与一线身份；补充材料能延迟输出。

持有者同样可以反制这些策略：先盖合同，再强化核心；把大招给稳定挡话角色；先转管理再等待下回合强化。第二学历与主技能争用同一回合机会，这些动作需要提前安排。

## 8.8 合体称号与主角造型

称号只读取两个槽位，用于UI、开场台词和分享卡。普通组合采用“第一学历出身·第二学历进修”；直接就业采用“毕业就上班”。

## 8.9 第一版的推荐组合

# 9. 留一手：隐藏反话

每人有一个反话位置。打出反话牌时，支付两小时，将牌盖住。对方只看到“留了一手”。触发条件成立后，反话自动翻开并消耗。

三张反话都耗时两小时，分别为《合同写着呢》《先问工时》《截图发群里》。它们分别防单目标拆台、削弱一次冲脸、惩罚已经发生的冲脸。相同的背面让对方需要用行动判断。

反话位已有牌时，无法再盖新的反话。反话无法主动丢弃或收回。开局选中的反话属于普通牌库，需要抽到才能盖下。

《合同写着呢》在敌方拆台牌已经支付费用、尚未执行效果时触发。它要求那张牌选择己方单个场上 Offer 为目标。群体伤害、直接打主角、英雄技能、角色上桌效果都不满足条件。

《先问工时》在合法开怼已经宣告、伤害尚未计算时触发，减少攻击角色本回合的排面。《截图发群里》在主角已经受到开怼伤害且对局仍继续时触发。

对手可以先用《追问细节》测试合同，也可以用小角色试探冲脸反话。留一手、试探、决定是否继续投入，构成这部分博弈。

| 编号／牌名 | 时间 | 效果 |
| --- | --- | --- |
| F01 三十五岁 | 2小时 | 给一个35岁的敌方一线Offer挂上优化通知。在你的下个回合开始时，若它仍是同一次上桌的35岁一线Offer，让它退场。 |
| F02 股权重估 | 2小时 | 对一个敌方Offer：先清除其期权条款提供的排面加成，使该条款本次上桌失效；随后使其失去2点底气。没有期权的目标只受到伤害。 |
| F03 转管理 | 2小时 | 一张友方Offer失去一线标签，排面-2，最低0；随后抽1张牌。转管理状态持续至收回或退场。 |
| F04 合同写着呢 | 2小时 | 对手下一张以你的单个Offer为目标的拆台牌，其全部效果取消。对手已付时间不退还。触发后消耗。 |
| F05 换个话题 | 1小时 | 选择聊年包、聊生活或聊以后，立即成为公共话题，持续至本轮结束。后使用的话题覆盖先前话题。 |

所有恢复效果受当前上限约束。“上限与当前底气各 +2”表示已受伤害保持不变。角色排面可以被降低到零，底气上限最低为一。

《补充材料》的限制只影响主动开怼，目标仍可反击。效果在目标拥有者下个回合结束后移除。多个相同限制只延长到最晚的已有到期点，不累计跳过多个回合。

《股权重估》清除 B04 的阶段排面加成，并令 B04 在本次上桌期间失效。其他来源的成长保留。收回后，B04 恢复，重新按保留年龄计算。

《转管理》移除一线标签，因此本次上桌不再承担一线主动开怼自损。其排面降低两点。收回会清除转管理状态，再次上桌恢复原本的一线身份。

# 11. 六种阵容思路与实际决策

## 11.1 高薪抢节奏

核心为一线卷王、销售冠军、低耗时助阵。学校优先搭配 985。利用谈薪把高排面角色提前上桌，配合《临时加班》与《反问环节》结束比赛。

这套打法要计算自己的心态损失。每次开怼、自损加攻、Offer 退场都可能让对手得到反杀空间。面对三十五岁应对牌，需要给《转管理》或《跳槽》留时间。

## 11.2 稳定续航

核心为稳定守岗、双休条款、老员工。学校可搭配一本。挡话保护恢复角色，利用聊生活阶段与恢复牌挡住第一波输出。

这套打法需要保留对高排面角色的处理手段。光恢复无法解决已经成长的对手。《预算砍半》《终面摊牌》提供重置场面的机会。

## 11.3 长期兑现

核心为硬件老法师、创业合伙人、期权条款。C9 的便条帮助提前部署。目标是让场上的关键 Offer 活到三十一岁，再围绕聊以后阶段形成持续优势。

对手会用回手、优化与股权重估拆解投入。长期牌持有者必须决定保护哪一张，也要防止把所有强化叠在同一个目标上。

## 11.4 流程拆台

核心为流程大师、人事终面官、咨询方案师。学校搭配清北或 211。通过信息、卡手、回手与抽牌控制对方行动。

这套打法依赖明确的结束手段。每次《面经复盘》都会缩短牌库寿命。后期需要把场面优势转换为心态伤害。

## 11.5 小牌打大牌

核心为校招生鼠鼠、实习搭子、拆台直伤。二本／双非技能持续补充场面。用小角色换掉高耗时 Offer，利用对方每次退场额外损失的心态赢得优势。

四个位置形成天然限制。无脑补人会卡住自己的关键 Offer。主动让一个助阵角色交换退场，也是在给后续部署腾位置。

## 11.6 谈薪调度

三张 Offer 分别承担抢节奏、稳场与长期兑现。根据对手的公开阵容决定哪张用于谈薪。同行业的三张高薪牌能够换来更大的谈薪优惠，也会减少低耗时阶段的自然选择。

每局只能谈一次，所以“什么时候公开放弃一张牌”本身就是信息。对手看到你的长期牌已经拿去谈薪，便可以把拆长期的工具转作其他用途。

# 12. 一段完整名场面

当前轮到甲。乙的互联网算法 Offer 已经三十五岁，仍有一线标签。乙还盖着一张反话。甲手里有《追问细节》《三十五岁》，剩余五小时。

甲先花一小时打《追问细节》，目标指向乙的 Offer。乙翻开《合同写着呢》，取消这张牌。甲还剩四小时，随后花两小时打《三十五岁》，给目标挂上通知。甲用剩下两小时部署校招生鼠鼠，然后结束回合。

乙得到一个完整回合。乙花两小时打《转管理》。角色失去一线标签，排面降低两点，乙抽一张牌。现在乙可以继续利用这张已经成长的 Offer 开怼，也可以把时间投入另一张牌。

轮到甲时，优化通知检查到目标已经失去一线标签，通知失效。甲消耗了试探牌与应对牌，乙消耗了合同与转管理，场上高薪角色也永久降低了本次上桌的排面。

战报可以写：“你把三十五岁当斩杀线，他把转管理当闪避键。”日志应分别记录试探、合同触发、通知挂起、身份转换、通知失效。没有发生的步骤不得补写。

这类局面让薪资比较获得真正的来回。对局中的吐槽随着操作发生，玩家会记住自己如何把一张现实 Offer 救了回来。

# 14. 美术规范：可爱的二次元小人

## 14.1 统一角色系统

每张 Offer 是一个独立职场角色。角色采用约 2.5—3 头身，头部比例偏大，脸部清晰，动作夸张。人物有成年职场身份，衣着以日常通勤、工装、实验室或商务服装为主。

玩家可以选择女性、男性或中性角色风格。外观选项不进入战斗计算。首发人物主体统一为人形，动物元素最多作为发夹、包挂或袖章。

美术气质是“看着很可爱，开口很欠揍”。默认表情带一点得意。受击时鼓脸、瞪眼、抱紧电脑；退场时工牌弹起，人物抱着箱子小步离开；胜利时露出忍不住的笑。

## 14.2 公司视觉进入角色的方式

公司 Logo 参与提取主色、辅助色、几何轮廓与品牌意象。颜色进入服装和配饰；几何形状进入发夹、领针、包袋与背景装饰；品牌意象转为道具轮廓。

清晰的公司简称、Logo、年包与岗位文字由前端单独排版。Logo 作为独立资产叠在卡框、工牌或卡片抬头上。角色插画留好相应空位。

生成顺序为：解析品牌视觉 → 确定角色身份 → 确定姿态与道具 → 生成无文字角色插画 → 前端合成卡框与信息。

## 14.3 岗位视觉字典

| 岗位 | 主要道具 | 姿态与神情 |
|---|---|---|
| 开发 | 笔记本、终端小窗 | 一手打字，一手扶咖啡，困得很骄傲 |
| 算法 | 节点投影、数据球 | 指尖推演图形，笑容过分自信 |
| 产品 | 平板、需求便利贴 | 正在指挥对齐，眼神机灵 |
| 运营 | 活动看板、扩音器 | 热情外向，准备再拉一个群 |
| 销售 | 手机、合同夹 | 身体前倾，准备完成最后一击 |
| 人事 | 印章、简历夹 | 礼貌微笑，另一只手已经准备盖章 |
| 测试 | 放大镜、故障贴纸 | 找到问题后的得意表情 |
| 制造研发 | 工装、量具、小机械臂 | 稳定站姿，手上有实际工具 |
| 设计 | 数位笔、色票 | 动作灵巧，神情略显挑剔 |
| 咨询 | 汇报板、文件袋 | 从容讲解，身边飘着小图表 |

每张卡主道具最多两个。背景只保留一个工作场景线索。公司性质决定服装细节，岗位决定主要道具，技能决定角色动作。

## 14.4 卡片信息布局

完整卡片采用竖向 3:4 比例。顶部放公司简称、岗位、上桌时间。中央以角色立绘为主体。下方以固定字号显示主技能与条款。底部并列显示排面、底气、年龄。

年包是一枚明显的工牌式标签，点击展开薪酬构成。风味文案放在规则框外，使用独立的聊天气泡。正面最多展示一个主技能与一个条款。

对局缩略卡只保留头像、排面、底气、年龄、重要状态角标。长按或点击可展开完整卡片。优化通知必须具有文字与图形标记。挡话、已开怼、无法开怼都采用不同轮廓。

## 14.5 插画交付规格

角色人物母版默认1024 × 1536、透明背景，完整卡片由前端合成为竖向3:4。单人、完整轮廓，四周预留约 8% 安全空间。画面不生成卡框、数值、汉字或品牌字样。

首发每张角色一张主立绘，五种表情采用共享叠层或预设头像。完整重画表情作为后续内容能力。手机牌桌使用裁切头像与压缩图，母版用于卡片详情和分享图。

# 15. AI 文案：甜脸、毒舌、对着这局说话

## 15.1 内容组成

每张 Offer 生成一个卡名、一句出场台词、一句开怼台词、一句被拆台台词、一句退场台词、一句胜利台词。规则文字由程序模板渲染。

卡名建议四至八个汉字，允许保留常见岗位缩写。单条台词建议八至二十四个汉字，最多三十二个字符。语气以短促、具体、有反转感为主。

吐槽对象优先选择年包构成、工时、岗位黑话、期权、年龄计时、学校流派与本局操作。角色要有稳定的说话方式，例如程序员冷淡自信、销售主动压迫、稳定岗慢悠悠地补刀。

## 15.2 强度设置

轻吐槽：“你这个成长空间，已经占满整张卡了。”

阴阳：“年包写得挺满，固定工资怎么只占半行？”

火力全开：“把期权算进工资的那一刻，你已经开始替老板融资了。”

默认使用阴阳。好友房可选择火力全开。公开展示采用双方确认的公开字段。用户可关闭对方语音与台词，战斗信息照常显示。

## 15.3 台词样例库

| 触发场景 | 示例 |
|---|---|
| 高薪角色入场 | “包是挺大，人已经拆封了。” |
| 低耗时角色打掉高薪角色 | “你的待遇写了三页，我的反问只用一句。” |
| 打出三十五岁 | “简历写熟练掌握，名单写熟练优化。” |
| 转管理避开优化 | “技术路线到头，汇报路线开张。” |
| 稳定角色撑到后期 | “你负责开场炸裂，我负责还在场上。” |
| 双休恢复 | “你又多卷一轮，我又少上一天。” |
| 期权被拆 | “饼画得挺圆，端上来就剩盘子。” |
| 谈薪成功 | “这份先不去，拿来给下一份上上压力。” |
| 合同挡住拆台 | “口头承诺归你，白纸黑字归我。” |
| 试探掉反话 | “刚才那句是试探，现在这句才算数。” |
| 学校技能取得优势 | “校名念完了吗？轮到我结算了。” |
| 连续抽牌把自己抽到焦虑 | “面经越看越多，心态越看越薄。” |
| 低薪阵容获胜 | “钱你确实拿得多，这局你确实没拿下。” |
| 高薪阵容被翻盘 | “年包挺能撑场面，场面怎么没撑住？” |
| 失败后再来一局 | “刚才算试岗，现在开始正式面试。” |

文案生成只读取用户确认字段与已经发生的事件。公司近期动向、真实团队行为、个人经历不能由文案模型补写。对局内最多每次关键事件播一句，每回合最多两句，避免语音刷屏。

## 15.4 输出校验

模型输出结构化 JSON。校验长度、重复度、字段引用与事件条件。禁止把规则文本放进台词字段，也禁止在规则字段中生成自由文本效果。

重生成台词使用新的文案种子，不改变规则哈希。质量不合格时切换到相同模板的固定台词库。每句台词记录适用触发条件，例如“成功优化”“优化被躲开”“小角色击倒大角色”。

# 16. AI 生成流水线

## 16.1 四个独立模块

**信息提取模块**负责把文本或图片内容转为字段。每个字段附带来源、原文片段与待确认状态。用户补填的内容记录为用户输入。

**规则编译模块**是确定性程序。它计算计价年包、薪资档位、模板与附加条款，输出数值和白名单效果编号。

**角色创作模块**读取确认字段、模板与品牌视觉描述，生成角色设定、卡名、性格、台词和绘图描述。它无法回写战斗数值。

**插画生成模块**读取固定美术规范与角色设定，只生成角色资产。前端合成统一卡面，展示可审阅的最终结果。

## 16.2 创建状态

创建流程使用：草稿 → 字段待确认 → 规则已生成 → 插画生成中 → 可以使用。

规则生成后即可使用临时头像试玩。插画失败时保留已有规则与文案，提供重新生成插画按钮。对局中不调用语言模型或绘图模型。每个角色在对局开始前冻结规则与可播放台词。

## 16.3 数据分层

`OfferProfile` 保存已确认的现实字段。`OfferDefinition` 保存规则版本、模板、条款和初始数值。`CreativeAsset` 保存角色设定、图片与台词。`OfferInstance` 保存某一局的年龄与使用记录。`DeploymentInstance` 保存某次上桌的伤害和状态。

同一张 Offer 可以拥有多套立绘。同一份定义可进入不同对局。已经谈薪、已经上桌、已经收回等信息只存在于对应对局中。

## 16.4 服务端保护与字段可见性

对手只能收到已经公开的公司显示名、游戏必要属性和用户选择展示的字段。原始文件、完整联系方式、申请编号、签字区域不进入战斗数据。

模型输入与用户文案作为数据处理。规则模块只接受枚举编号和经过校验的数值。上传内容中的命令无法新增效果、修改属性或读取服务端密钥。

隐藏手牌、牌库顺序、未翻开的反话仅存在服务端真实状态中。客户端收到针对自己的视图。清北窥视与战报导出分别调用明确的信息披露逻辑。

原始文件支持生成后删除。用户删除个人 Offer 时，收藏记录和原始资产按产品数据流程移除；历史战报只保留当时允许公开的展示快照。

# 17. 程序必须实现的时序

## 17.1 一轮开始

增加轮次 → 恢复该轮默认话题 → 开始先手回合。后手回合完整结束后，进入下一轮。

## 17.2 一个回合开始

依次执行：结算本回合到期的优化通知；执行胜负检查；为当前玩家已有的场上 Offer 推进年龄；重新计算阶段属性；执行胜负检查；补满时间；重置共享学历行动与主动开怼次数；抽一张牌；执行胜负检查；进入玩家行动阶段。

优化通知按创建顺序结算。年龄推进只处理回合开始时已经在场的 Offer。重新上桌不会直接获得额外年龄推进。

## 17.3 一次开怼

验证目标与次数 → 消耗本回合的主动开怼次数 → 检查开怼前反话 → 重新计算排面 → 同时结算交锋伤害与一线自损 → 同时清理本次底气归零的角色 → 同时结算 Offer 退场心态损失 → 检查胜负 → 依次结算开怼后的反话与抽牌。

一线的自损只由主动开怼触发。被动反击不会自损。即使一线角色在这次交锋中退场，本次主动开怼自损仍然包含在伤害节点中。

排面被《先问工时》降到零后，已经宣告的开怼仍继续，主动次数不退还。对主角造成零伤害时，不触发销售抽牌或《截图发群里》。

## 17.4 一张拆台牌

验证目标与费用 → 扣时间、移出手牌 → 检查《合同写着呢》 → 按文本顺序执行效果 → 每个伤害节点清理退场并检查胜负 → 剩余效果完成后写入日志。

合同取消整张牌的效果，包括牌上附带的抽牌或恢复。被取消的牌照常进入弃置区，时间不返还。

## 17.5 回合结束

执行己方场上 Offer 的回合结束能力 → 结算聊生活额外恢复 → 清理到期的本回合效果与返场便条 → 写入回合结束事件 → 移交行动权。

多个己方结束效果按从左到右的场上位置顺序执行。临时加排面、开怼限制、清北加时分别使用自己的明确到期时点。

## 17.6 收回与重新上桌

收回保留：Offer 身份、规则版本、已达到的年龄、它曾经使用过的事实。

收回清除：伤害、本次上桌的强化与削弱、优化通知、转管理、期权失效、保障条款已使用状态、主动开怼次数。

重新上桌：创建新的上桌实例，按原本规则与保留年龄重建属性，重新执行上桌效果。曾经上过桌的 Offer 即使再次回到手牌，也无法作为谈薪筹码。

## 17.7 派生属性与特殊状态

当前排面统一为“生成时排面 + 年龄技能加成 + 有效条款加成 + 话题加成 + 本次上桌增减”的总和，最终最低为零。当前底气等于“生成时底气上限 + 年龄增加的上限 + 其他上限增减 − 已受伤害”。恢复减少已受伤害，最低减到零。

所有修饰都记录来源与到期时点。期权失效只禁用 B04 的来源。一线身份由当前职业标签决定，转管理同时关闭一线自损。保障条款只减对手拆台牌造成的底气伤害，群体伤害也可消耗它。直接退场与角色交锋不会消耗保障。

后置触发的固定顺序为防守方反话、攻击方命中后的抽牌。每项触发后执行胜负检查，已经结束的对局停止剩余触发。上桌时需要选目标的效果在提交动作时提供目标；标有“可以”的效果允许不选。

## 17.8 确定性与联网

状态变更只由规则引擎处理。建议采用纯函数形态 `applyCommand(state, command) -> nextState + events`。战斗计算不依赖动画帧、系统当前时间或模型回复。

服务器接受出牌、开怼、英雄技能、谈薪、结束回合等命令。每个命令携带递增序号与幂等标识。重复消息只处理一次。随机洗牌使用对局种子；事件日志能重建同一最终状态。

动画订阅事件，不能反过来决定规则。断线重连获取当前公开视图与未播放的关键事件。对局计时继续运行；连续两个自己的回合无有效操作且超时，判负。

# 18. 页面与交互

## 18.1 首页

首页主按钮为“拿 Offer 开打”。次按钮为“先玩一局”。下方展示最近生成的三张角色卡和最近一条名场面战报。

## 18.2 生成页

左侧或上部展示输入，右侧或下部展示角色卡预览。字段确认、条款选择、角色性别风格、台词强度分别分组。

生成后提供“换张脸”“换句狠话”“查看生成依据”“带去开打”。重新生成外观时继续显示固定的排面、底气与上桌时间。

## 18.3 配队页

上方分两个槽位选择第一学历与第二学历，实时显示主技能和进修技能；中间放三张 Offer，下方选基础牌组。系统显示早期可用牌数量、是否具备挡话、是否有抽牌、是否有处理大角色的手段。

公共体验卡与个人 Offer 可混搭。卡牌已被选入时显示明确状态，避免重复选择同一身份。

## 18.4 手机牌桌

顶部为对方主角、心态、剩余手牌数量与三张公开 Offer 的缩略栏。中部上半是对方四个位置，中部下半是自己四个位置。话题条横跨两排角色之间。

底部为自己的手牌横向滑动区。自己的三张 Offer 放在手牌上方的独立抽屉。第一学历技能、第二学历技能、谈薪、剩余时间、结束回合保持固定位置。两项学历技能并排共用一枚“本回合还可发动1次”的提示。校友流派签到章显示在主角旁。

点击选牌，再点击合法目标完成操作。拖动作为补充方式。手指按下时显示规则卡，松开选择目标。无法执行时直接显示“还差一小时”“场上位置已满”等原因。

## 18.5 战报页

首先展示胜负与关键角色。随后用三条事件串起转折，例如“用追问细节试出合同”“三十五岁挂上通知”“转管理成功躲开”。

分享图包含角色立绘、双方双学历称号、关键事件与房间入口。公开字段按生成战报时的设置确定。战报可以出现“本局最值回票价”“把工资打成工伤”等趣味标题，标题要匹配实际事件。

胜利页的主按钮为“同样阵容再来”。次操作是“换三张应对牌”。邀请别人进入时优先提供同局规则的房间或使用公共卡立即体验。

# 19. 音效、演出与节奏

上桌使用工牌落桌声。谈薪使用邮件发送与盖章声。抽牌使用消息提示声。英雄心态下降使用手机震动式短音。挡话时角色向前半步，像把对方的话接过去。

三十五岁通知采用日历翻页与邮件弹窗。转管理把键盘换成会议本。合同触发出现一张盖章文件。Offer 退场用角色收拾箱子的短动画。

普通反馈目标为零点一五至零点三秒。大牌上桌演出目标不超过零点八秒。反话翻牌目标不超过零点五秒。连续事件合并播放，提供加速选项。

角色语音优先采用短句。一回合最多两句，拖动、思考、窥视手牌时不播放盖住信息的演出。

# 20. 新手教学

教学分五段，每段聚焦一个新决策。

第一段教时间、上桌、开怼与心态。使用一张高排面 Offer 和两张简单助阵角色，完成一次角色交换和一次冲脸。

第二段教谈薪。给出两张不同价值的筹码，直接展示能提前几轮上桌，要求玩家选一次。

第三段教年龄与反制。用一张三十五岁的一线角色演示通知，再让玩家用转管理保住它。

第四段教话题与反话。用便宜拆台试出合同，转移话题改变场上优势，然后进入完整对局。

第五段教双学历共用机会，预置第四轮场景，演示主技能与进修只能选一个。附带可跳过的校友流派练习，完成集合、释放和被收回的反馈。

教程机器人明确标识为练习对手。教学结束直接进入好友房创建页，旁边保留公共卡对战入口。

# 21. 数值测试与产品验收

## 21.1 规则验收

配套 `acceptance_tests.md` 给出逐条测试。重点覆盖薪资边界、条款扣点、谈薪原子性、通知窗口、回手年龄、卡牌上限、反话优先级、同时退场、断线重连与隐藏信息。

规则测试必须在界面制作前可以单独执行。每张卡至少有一个成功案例、一个非法目标案例、一个与其他核心机制交互的案例。

## 21.2 平衡观察

按学校流派、Offer 模板、先后手、年包档位、应对牌选择分别统计。对局样本按真人与不同策略机器人分开，不把不同能力的玩家混成一个强度结论。

优先观察是否出现固定的谈薪套路、是否人人必带三十五岁、是否一个学校技能占据明显优势、是否三张高薪牌在所有时间段都占优、是否防守阵容经常依赖第十二轮判定。

调参顺序是：通用牌费用与效果 → Offer 模板身材 → 英雄技能 → 谈薪优惠 → 主角心态与时长。薪资档位边界尽量保持稳定，避免玩家短期内反复重学自己的卡。

## 21.3 首轮内部目标

| 指标 | 起始目标 |
|---|---|
| 完成教程的玩家中，完整打完第一局 | 至少 80% |
| 完成第一局后主动再次开局 | 至少 40% |
| 对局时长中位数 | 4—7 分钟 |
| 对局结束后，玩家能说出一个影响胜负的操作 | 至少 70% 的访谈样本 |
| 双方至少打出一张自己的 Offer | 至少 90% 的完整对局 |
| 因第十二轮上限结束 | 低于 15% 的完整对局 |

以上数值用于本项目内部迭代。分享率、邀请成功率、台词重生成率、插画成功率同步记录，初期先观察真实基线。

# 22. 开发拆分与交付顺序

第一阶段完成规则内核。实现三十张通用牌、十个第一学历与十一个第二学历技能、所有 Offer 模板、年龄、话题、谈薪、反话、胜负与回放。使用固定测试数据与默认头像即可对打。

第三阶段接入 Offer 输入和创作流水线。实现字段确认、规则编译、角色文案、插画任务、卡面合成、收藏修订和生成失败恢复。

第四阶段完成好友房、服务端裁定、重连、分享入口与数据记录。用真实好友对局验证局长、信息密度和阵容选择。

首发交付以完整可重复对战为终点。天梯、交易、多人混战、跨季职业养成、动态实时语音和大规模卡牌扩展放入独立后续版本。

# 24. 美术生产与内容覆盖

# 25. 机器人、回放与名场面

练习对手提供进攻、控制、养成三种策略。机器人只读取当前玩家可见的信息，通过与真人相同的命令入口行动。隐藏手牌、反话真实身份、牌库顺序不进入机器人评分函数。清北主动查看后，机器人才能使用该快照信息。

回放保存冻结定义、双学历组合、种子、已接受命令和事件。战斗结束前的回放视图按照身份过滤，普通玩家无法借重连接口取得另一方秘密。

名场面优先识别：小牌拆大包、低心态反杀、谈薪抢跑、三十五岁被转管理化解、合同被试探、校友流派大招成功保场、校友流派大招被收回、双校友流派叠加成功。文案只读取对应事件。大招释放不自动代表胜利。

# 27. 新增体验验收

第四轮开始时，第二学历按钮点亮一次，提示“进修技能可以用了”。本回合使用主技能后，第二学历应显示“这轮已经用过学历技能”；使用过进修技能后显示“本局已兑现”。

校友流派从0章到1章、2章、释放、饭局的全部状态都需要明确图标。对手可见同样的章数。满章且没有己方Offer时，按钮显示“先让一张Offer上桌”。

技能造成窥视或需要多选时，客户端进入有期限的选择状态。查看隐藏牌后不提供无损撤销。超时使用服务端稳定默认选择。对手不会通过目标提示、音效或进度条提前得知未揭示牌。

单局必须验证双学历共用行动、校友流派一次上限、收回清强化、年龄保留、降费下限、第二学历发牌时的满手与焦虑。素材路径检查、双浏览器好友局、移动端走查都进入交付报告。
