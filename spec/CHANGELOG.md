# v2.0.0 变更记录

学校系统由六个单技能主角升级为十个第一学历与十一个第二学历选择，共110种有序组合。海外档位定为1至50、51至100、101及以后。

第二学历第四轮解锁，每局一次。两个槽位每个自己的回合共用一次学历行动。直接就业作为第二槽位的完整可玩选择。

C9便条升级逻辑、返场便条、学校加时最大值、收回清强化和英雄技能来源补充为明确规格。原有30张通用牌、11种Offer模板、7种条款与薪酬档位保持。

开发资料扩充为一次性执行入口、工程启动合同、联网状态规格、原创美术设定、190槽位素材清单、独立生成提示词、48条事件台词、10套示例牌组、5个演示场景、178项完整游戏验收要求，以及41项已执行的学历参考模型测试。
