# 平衡测试与交付验收

## 1. 原型要检验的假设

双学历让主技能有稳定身份，同时用一次进修提供转折。共享行动机会控制同回合爆发。第四轮解锁让开局不出现两项技能一起争夺注意力。

校友流派在准备阶段累计支付4小时，只获得2点恢复。大招再花2小时提供＋4／＋4，回手、直接退场与优化能处理强化目标。大招之后的2小时恢复2心态提供有限续航。实际胜率、登场率和兑现收益需要通过完整对局测量。

双校友流派在同目标上累计＋6／＋6需要9小时、四个不同己方回合的学历行动，且依赖目标持续留场。叠加不提供年龄重置或主动开怼刷新。

## 2. 三层测试

资料一致性层：检查ID、费用、组合数、资源引用、例卡哈希和规则版本。

规则行为层：按照acceptance_tests.md与tests/education_acceptance.md实现自动用例。每种新技能至少覆盖有效目标、非法目标、耗时、共享机会、边界状态和回手。

对局层：执行110个组合的烟雾运行，交换先后手，与固定策略对手完成至少220场。额外运行三种牌组在不同机器人策略下的对局，输出样本、结果和失败动作。

## 3. 必须采集

记录firstId、secondId、offerTemplates、salaryTiers、deckPreset、firstPlayer、winner、roundCount、mindRemaining、primaryUses、secondaryUseRound、分阶段技能准备轮次、释放轮次、目标存活与强化后收回记录和matchEndReason。

对分阶段技能额外记录是否通过谈薪提前部署、是否因空场不能释放、是否在强化后当回合完成斩杀。对海外返场记录原始耗时、最终耗时和返回次数。

## 4. 平衡警报

某个组合在三种不同基础牌组中都稳定取得明显优势，进入人工复核。某项进修在大多数可用对局中完全不发动，检查目标条件和费用。校友流派在所有合理场面都优于其他主技能，优先检查大招目标、次数、回手和成本是否实现正确。

样本不足时显示样本量。机器人差异单列。平衡报告不要把模拟的少量胜率写成精确的真人结论。

## 5. 调参顺序

先修规则实现错误。随后调通用应对牌与主角技能成本。分阶段强化技能允许的下一版调参方向为大招＋3／＋3至＋4／＋4、释放成本2至3、集合回复0至1；改版必须增加rulesVersion，并同步文本和测试。

2.0.0交付仍严格使用两次集合各2小时、大招2小时＋4／＋4、进修3小时＋2／＋2。模拟发现失衡时将证据写进报告，保持当前验收版本可复现。

## 6. 真正的交付门槛

| 检查 | 通过表现 |
|---|---|
| 零密钥 | 清空所有外部模型配置，仍能录入、成卡、配队、整局对战 |
| 双学历 | 110种组合可选择，第二技能第四轮解锁，共享机会有效 |
| 资源 | 清单中每项必要资源映射到真实文件，PNG/SVG/音频能读取 |
| 校友流派 | 准备、READY、释放、SPENT都有清楚表现，六个装饰校友不占场 |
| 朋友对战 | 两个独立浏览器上下文可以创建、加入、选择、对战、结算 |
| 重连 | 断开连接后恢复原座位与可见状态，未泄漏秘密 |
| 机器人 | 通过同一命令层行动，牌组合法，能完成整局 |
| 移动端 | 360与390宽度无关键遮挡，可以点牌、选目标、操作技能 |
| 分享 | 比牌邀请、名场面、双学历毕业照可以生成可读图片 |
| 构建 | 生产构建启动后全部页面与素材依然可用 |

## 7. 低依赖的加分项

保留一键重赛、可跳过的五段教学、战斗日志展开、三张自选应对牌、降低动画、关闭嘴炮、固定种子重演。这些都直接服务首次完整体验。

先完成已定义的玩法与资源。支付、开放交易、复杂养成、全平台客户端和实时自由聊天独立安排。创作预算用于角色辨识度和牌桌反馈。
