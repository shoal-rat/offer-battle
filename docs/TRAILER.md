# 30 秒，把 Offer 摆上桌

朋友晒年包，自己晒双休。这支宣传片把熟悉的聊天场景接到真正的做卡、邀请和交锋：工资是开场，下一手才是故事。

[观看宣传片与实机截图](https://weikezhang.cn/offer-battle/about/#film) · [直接试玩](https://weikezhang.cn/offer-battle/)

## 画面从哪里来

宣传片使用 2.2 公测版游戏界面录制。28 万、双休的“制造业研发”由实际做卡表单保存，并用于后续同一场演示对局；好友房由两个隔离的本地浏览器会话实际创建和加入。线上好友联机需要注册账号。

为在短片里展示一段清楚的来回拆台，拍摄使用合法规则回放还原的存档：从正常开局执行 31 条合法指令得到第 9 轮局面，再通过双浏览器界面连续完成最后 6 条指令。没有修改费用、攻击、血量、牌的效果或胜负规则。专用本地拍摄服务器延长了操作计时，准备和等待在剪辑中被缩短。

三十五岁挂上通知，转管理使其在下一次检查时失效；校招生鼠鼠与算法岗双方退场，对方心态从 5 降到 3；反问环节再使其降到 0。拍摄后的 37 条完整指令重新经过当前规则核心，所得最终状态与录制服务器存档一致。片中数值、角色退场与结果均来自游戏本身。

## 一张纸的剪辑台

使用免费开源的 [Shotcut](https://www.shotcut.org/) 制作，保留可编辑的实机、纸底、文字、人声、音乐和音效轨道。两位角色采用两条不同的合成声线；配乐与音效来自游戏随包素材。纸片角色与宣传封面沿用当前游戏的原创美术。

成片以竖屏展示，提供带宣传字幕与无宣传字幕版本；后者保留实机界面的卡名、规则和结果文字，便于后续制作其他语言的宣传包装。海报另有竖版与横版，适合分享封面及 GitHub 项目展示。

这是一支演示对局实录剪辑。它展示已经运行的功能，不承诺胜率、薪酬评价或现实求职结果。关于完整游戏验证范围，见 [公测 QA](QA_BETA_2.md) 与 [测试报告](../TEST_REPORT.md)。
