# 2.2.0-beta.2 交互与演出验收补充

2026-09-27 的后续明确需求采用默认直接出牌和较慢、可辨认的实体交锋。本补充覆盖原 2.2 升级包中冲突的点击流程与时序要求。原始规格、历史日志和失败样本保留；这里调整的是当前预期，不是把旧失败改记通过。

## 当前行为契约

| 操作 | 当前预期 |
| --- | --- |
| 普通牌与无需指定目标的上桌操作 | 默认单击或拖到合法桌面即用，不要求先打开规则、再点使用、再确认 |
| 有目标的 `PLAY_CARD` / `DEPLOY_OFFER` | 进入纸飞机瞄准，选择实际合法目标；完整动态下飞行 650 ms、展开 350 ms 后提交 |
| 场上角色 `ATTACK` | 选中己方角色后点击合法目标，直接进入 1,180 ms 实体冲撞；不重复纸飞机段 |
| 取消待发牌 | 提交前可取消；不产生指令、不扣游戏内可用小时或资源。好友的真实回合倒计时仍照常运行 |
| 放大读牌 | 显式可选；读牌模式及规则详情不自动使用卡牌 |
| 技能与特殊操作 | 技能说明和可用原因可读；谈薪与有剩余攻击时的结束回合保留必要提醒，不把它们误当普通卡牌的多次确认 |
| 权威结果 | 飞机属于提交前反馈；收到合法结果前不预扣数值、不揭示未知反话，提交仍检查当前版本 |
| 实体攻击 | 1,180 ms，总过程含 640 ms 接触节点。原角色 `visibility:hidden`，原格位保留；飞行有姓名与攻防对象提示，不在原地留分身 |
| 退场与补位 | 残影 460 ms；残影消失前保留格位，其后补位。正常回归的相邻角色横向位移仍要求小于 1.5 px |
| 有最后一击的终局 | 完整攻击后接 650 ms 收尾，设计总预算 1,830 ms，展示上限 2,000 ms；不得仍要求旧 900 ms 上限 |
| 展示积压 | 超过 3,000 ms 压缩，超过 5,000 ms 追到当前状态；替代旧 1,200/2,000 ms 阈值 |
| 取消、后台与减少动态 | 保持清理和状态一致性；减少动态不要求执行完整飞行时长，后台不补播旧动画，不增加正式回合期限 |

## 与旧验收编号的关系

- **UI04 / Q27–Q30：** 普通模式的首次点牌是使用意图；可选读牌才是阅读意图。有目标的出牌提交前取消仍须无消耗；场上角色攻击直接冲撞。鼠标、触摸、键盘、拖拽状态变化和多目标能力仍按实际行为验证。
- **UI05 / Q33：** 公开结果提示和未知信息边界保留；不再要求每张牌都有强制预览弹窗与“确认行动”按钮。
- **Q93 / Q104：** 按较慢攻击、单一可见实体与退场占位检查，目标 ID、接触与伤害因果仍必须正确。
- **Q95 / Q96：** “确认前”指权威请求尚未成功，不等于必须多一次玩家点击。纸飞机不能提前改变权威状态；状态过期或取消时不得提交旧目标。
- **Q99：** 当前展示积压阈值为 3,000/5,000 ms，日志因果和追帧一致性要求不变。
- **Q37 / Q38 / Q100 / Q102 / Q105：** 演出可取消、回放不重播旧事件、回合期限和偏好优先等要求不变。

机器可读对应关系见 [acceptance-overrides.json](../reports/upgrade-v2.2/acceptance-overrides.json)。本补充不改变独立验收的 `not-run` 状态。

## 发布前完整体验补充

- “慢慢练习”包括应对选择、换起手、正式回合与重赛，全部 `deadline=null`。旧练习存档中的开局期限须在恢复前清除；普通计时人机及好友仍计时。
- Local/Node 默认机器人动作间隔为 1,280 ms，避免下一步覆盖 1,180 ms 攻击；测试显式间隔配置继续有效。Cloudflare 不承载人机，不能把练习标记用于关闭好友期限。
- `flexSelection` 只返回给自己的视图；对手与观察者不得得到该字段。旧 Worker 未返回它时，界面使用已选阵容的 `preferredFlex`，不能假装它是服务端返回的新状态。
- 从桌面切换到窄屏时收起 Offer 抽屉，避免它压住攻击目标或其他操作。

## 现有证据的范围

本地生产构建已经执行布局/全屏/音频 10 项、新交互动画 3 项；详细命令、环境、帧数据、哈希与旧失败见 [专项证据](../reports/upgrade-v2.2/beta2-interaction-evidence.json)。上述 13 项为后续完整手测修补前的开发构建，不证明最新攻击分流、应对牌回退或窄屏变化已经复测。慢练习与默认机器人节奏另有 [32+1+11 项后端记录](../reports/upgrade-v2.2/beta2-practice-evidence.json)。这些批次不包含完整 48 个独立会话、全部键盘/多目标矩阵、真机性能或正式公网联机。

A01/A02 继续使用盲测提示，不提供按钮、选择器或操作答案。具备专项测试权限的角色按本补充判断当前行为。A09 当前不能原生观看正常速度视频，只能实际录制视频并复核连续时码帧；该能力缺口与正常速度观察保持 blocked。A08 只对真正成对的匿名场景比较；缺少旧版图的场景不得被推定通过。

正式会话须等待 beta.2 提交推送、网页发布及受测构建冻结；不把开发浏览器回归、工具链 smoke 或历史代理报告计为新样本。

发布前主开发代理已完成一整局实际体验与修复，见 [试玩记录](../reports/upgrade-v2.2/root-hands-on-beta2.md)。按用户最新要求，本轮优先上线，48 次独立会话和最终 A08 重拍后续再执行，保持未执行状态。
